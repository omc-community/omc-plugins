This repository publishes two dedicated plugin registry lists (plus an aggregated index) for the
[Oh-My-CPA](https://github.com/WizisCool/oh-my-cpa) (OMC) and
[CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI) (CPA) ecosystem:
- **`official.json`**: Plugins developed, maintained, and verified by the core Oh-My-CPA team.
- **`community.json`**: Community-contributed plugins, extensions, and integrations.

---

## Configuration & Usage

### Oh-My-CPA (OMC)

Oh-My-CPA connects to the aggregated source by default. You can manage or add individual sources (`official.json` or `community.json`) under **Settings → Plugins → Plugin Store**.

### CLIProxyAPI (CPA)

Add desired source URLs to `plugins.store-sources` in your `config.yaml`:

```yaml
plugins:
  enabled: true
  store-sources:
    - https://raw.githubusercontent.com/omc-community/omc-plugins/main/official.json
    - https://raw.githubusercontent.com/omc-community/omc-plugins/main/community.json
```

## Contributing a Plugin

We welcome extensions, OAuth providers, and tools for the Oh-My-CPA ecosystem! To add a plugin to this registry:

1. **Fork** this repository.
2. Edit **`community.json`** (or `official.json` for core team extensions) and add your entry under the `plugins` array.
   > **Note**: `registry.json` is automatically generated by CI from `official.json` and `community.json` (officially maintained plugins are guaranteed to always be ordered strictly above community plugins). You do not need to manually edit `registry.json`.
3. Validate your entry against CPA's registry requirements:
   - `id`: Unique identifier matching `^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$`.
   - `name`: Clean human-readable display name.
   - `description`: Single clear sentence summarizing capability.
   - `author`: Maintainer name or organization.
   - `repository`: Full GitHub HTTPS address `https://github.com/{owner}/{repo}` (no `.git` suffix, no shorthand).
   - `version`: Display fallback version matching `^[0-9][0-9A-Za-z.+-]*$` (no leading `v`).
   - `install`: `{"type": "github-release"}`.
   - `locales`: Optional localized descriptions (`zh-CN`, `zh-Hant`, `ms`, etc.).
   - `logo`: Direct HTTPS URL to artwork or SVG/PNG asset.
4. Run validation tests (or locally generate with `go run ./scripts/generate.go`):
   ```bash
   go test -v ./...
   ```
5. Submit a **Pull Request**.
